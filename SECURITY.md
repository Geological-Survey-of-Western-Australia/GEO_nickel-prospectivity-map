# Security Policy

This security policy applies to the Geological Survey of Western Australia nickel prospectivity mapping repository on GitHub ([nickel-prospectivity-map](https://github.com/Geological-Survey-of-Western-Australia/nickel-prospectivity-map)), published by the Geological Survey of Western Australia. The code is made publicly available to support transparency and reproducibility of the associated work. The repository is archived on release and is not actively maintained or supported.

## Security Notice

Security scanning was performed during the development and build process. The results reflect the state of the product and its dependencies at the time the scans were performed.

Security scans may not identify all vulnerabilities and may be subject to false positives or false negatives. Unless otherwise stated, no additional security scanning, validation, monitoring or assurance activities have been undertaken following completion of the build process. Users are responsible for conducting their own testing, validation and security assessment before deploying, implementing or otherwise relying on this product.

## Security/Bugfix Versions

No security or bug fixes are provided for this project. Because the repository is archived on release, reported vulnerabilities will not result in patches or new versions. If you use this code, you are responsible for maintaining your own copy, including updating dependencies and applying any fixes.

## Scan Coverage

Packages declared in `environment.yml` were looked up in JFrog Xray by PyPI name and version. Packages without a pinned version, and conda packages with no PyPI equivalent, are not covered by this scan. The absence of a finding is therefore not confirmation that a package is free of vulnerabilities.
